
# 一些问题

## 使用构造器注入

在spring 3中，构造器注入，必须显式的添加@Autowired注解，否则spring会尝试使用无参构造器，这时如果没有无参构造器，就会抛错。
```text
    private final Test1Service test1Service;
    
    @Autowired
    public OrderController(Test1Service test1Service) {
        this.test1Service = test1Service;
    }
```
直到spring 4.3.x版本，构造器注入，不再需要添加@Autowired注解。
